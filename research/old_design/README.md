# Old design

Documents of the design that was replaced on 2026-10-04. They do **not** describe the
current experiment; that is in `experiment/README.md`. They are kept for the reasoning
and the sources behind choices that still hold (for example why the CVs carry no names:
`design_decisions.md`, D03).

What changed since: 20 jobs with one CV each instead of 6 jobs with 48 CVs; every job in
all 22 Arab countries instead of 8 fixed ones; no cities, school or company names; 6
comparison nationalities instead of 11; a main prompt plus a follow-up message; a
lottery option; a promotion scenario; no principle probe. The code, settings and
analysis plans these documents refer to were removed (git history, commit 670f827).

| `experimental_design.md` | the full design |
| `design_decisions.md` | each design decision with its sources |
| `hypotheses.md` | research questions and hypotheses |
| `variables.md` | every variable |
| `threats_to_validity.md` | what could go wrong, and the answers |
| `design_contract.md` | the specification the removed code was built against |
| `status_report.md` | status as of 2026-10-01 |

## Framing

The same line of argument as `paper/proposal/proposal.tex`:

- Starting point: a documented bias against Arabs and Muslims, in every study for one
  pooled group.
- Question: does a model see some of the 22 Arab League nationalities more favourably
  than others?
- The bank's customer check is the measuring tool, chosen because the nationality cannot
  be removed from it and because the rules say how far it may count.
- Arab is not the same as Muslim. The files state no religion, so the project measures
  how nationalities are treated, not bias against Islam.
- Do not say that banks let LLMs decide on customers. What the products do is not
  public.
